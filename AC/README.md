# AC — Arquitectura de Computadores

Prácticas de la asignatura de Arquitectura de Computadores en la FIB (UPC).

## 🛠️ Tecnologías
- C
- Ensamblador x86 (`.s`)

## 📁 Contenido

Prácticas de programación de bajo nivel:
- Programación en ensamblador (manipulación de registros, acceso a memoria)
- Medición de rendimiento y conteo de ciclos
- Interacción entre código C y ensamblador
