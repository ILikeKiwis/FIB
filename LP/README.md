# LP — Lenguajes de Programación

Prácticas de la asignatura de Lenguajes de Programación en la FIB (UPC).

## 🛠️ Tecnologías
- **Haskell** — programación funcional
- **Python**

## 📁 Contenido

### Haskell
Ejercicios sobre:
- Tipos de datos algebraicos (árboles, colas, pilas)
- Clases de tipos: `Show`, `Eq`, `Functor`, `Applicative`, `Monad`
- Pattern matching y recursión
- Evaluación perezosa y listas infinitas
- Manipulación de expresiones lógicas

### Python
Ejercicios y scripts desarrollados a lo largo de la asignatura.
